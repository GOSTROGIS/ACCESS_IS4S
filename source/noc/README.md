# Complete NOC coverage

The finder at `tools/noc/` uses the **complete NOC 2021 Version 1.0** classification: 516 unit groups and 27,935 official English example job titles, plus French unit-group titles. The quick-pick buttons are examples, not a scope restriction. The directory exposes every unit group in all ten broad categories, with trades and transport first. The category 7 directory alone is not all trades: cooks, hairstylists, bakers and horticulturists are classified elsewhere.

NOC is an occupational classification, not a registry of all provincial apprenticeship programs or Red Seal designations. The source does not guarantee every regional, employer-specific or new job-title spelling. Users should confirm main duties against the official profile.

## Data provenance and verification

Source: https://www.statcan.gc.ca/en/subjects/standard/noc/2021/indexV1

On 2026-11-09, downloaded the three official CSVs listed in `tools/noc/build_noc_data.py`, regenerated the dataset with its original download-date metadata (`2026-11-07`), and compared the generated bytes with `tools/noc/noc-data.js`. They were identical. The existing data therefore needed no additions or invented mappings.

To repeat, download those unchanged CSV files into RAW_DIR, then run:

    python3 -I tools/noc/build_noc_data.py RAW_DIR /tmp/noc-verified.js 2026-11-07
    cmp tools/noc/noc-data.js /tmp/noc-verified.js

## Tests

Dependency-free data, directory, runtime rendering and search regressions:

    node source/noc/test-data-search.cjs

Full browser interaction and mobile-width tests (requires Playwright and Chromium):

    node source/noc/test-finder.cjs

If needed, set `PLAYWRIGHT_MODULE` to the installed Playwright module and `CHROMIUM_PATH` to the browser executable. The browser test covers directory selection, query links, cross-category trades, French search, codes with leading zeroes, pagination, clear and mobile overflow.
