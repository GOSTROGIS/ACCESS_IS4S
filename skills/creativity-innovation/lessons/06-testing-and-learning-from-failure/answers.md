# Testing an idea and learning from what fails

## Task 1 (level 1)

Any sketch and prediction. A good response shows the arm, where it is taped and where the cup hangs, and gives a number for the prediction. The prediction does not have to be right.

## Task 2 (level 2)

Open task. A good build uses only the allowed materials, reaches 15 cm past the table edge, and is made following the safety steps: glasses on while knives are in use, cutting on a mat, blade retracted when set down.

## Task 3 (level 2)

Open task. A good record has three trials for version 1, the average worked correctly, and a short, plain description of how it failed (for example, "folded down at the table edge", "tape peeled off the table", "cup handle tore").

## Task 4 (level 2)

Answers will vary. A good response:

- observation: what was seen, with a number and a place ("The arm bent at the table edge at 9 washers.")
- guess: a possible cause ("A flat strip is too floppy.")
- check: a test that would show whether the guess is right ("Fold the arm into a tube and see if it still bends there.")

## Task 5 (level 2)

Open task. A good response:

- names the one change made for each new version
- tests each version three times and records the average
- tries the reverse prompt at least once (for example, a tie pulling from above instead of a brace pushing from below)
- notes when the way it fails changes, since that points to the next weak spot

## Task 6 (level 3)

a) Version 1: (6 + 7 + 8) ÷ 3 = 21 ÷ 3 = 7 washers. Version 2: (12 + 13 + 14) ÷ 3 = 39 ÷ 3 = 13 washers.

b) (13 − 7) ÷ 7 × 100 = 6 ÷ 7 × 100 ≈ 85.7%.

c) Depends on the team's data. Check that brackets are worked first, that the old average is the one divided by, and that the answer is rounded to one decimal place. If the old average is zero, percent improvement is undefined: report the change in washers instead of dividing by zero. A lower new average is a decrease, not an improvement.

## Task 7 (level 2)

Open task. A good test report:

- says how each version failed, using observations
- names the one change made each time and the reason for it
- states what was learned ("the weak spot moved from the arm to the tape")
- proposes a next change
- the team shares one useful tip with another team

## Task 8 (level 3)

a) Design A: (180 + 175 + 185) ÷ 3 = 540 ÷ 3 = **180 kg**. Design B: (260 + 250 + 270) ÷ 3 = 780 ÷ 3 = **260 kg**.

b) (260 − 180) ÷ 180 × 100 = 80 ÷ 180 × 100 = 44.44..., about **44.4%**.

c) Yes, if only the second U-bolt changed. Check that the pipe size, the rig, the way the load was added and the tightening of the bolts were the same for both designs.

d) Supports in a real building must follow the engineered drawings, the specifications and the manufacturer's ratings. A bench test helps compare ideas, but it does not replace the approved design.
