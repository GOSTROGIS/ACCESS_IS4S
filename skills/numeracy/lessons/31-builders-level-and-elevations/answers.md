## Task 3 (level 2)

| Point | BS | HI | FS | Elevation |
|---|---|---|---|---|
| BM1 | 1.632 | 101.632 | | 100.000 |
| TP1 | 2.104 | 102.891 | 0.845 | 100.787 |
| TP2 | 0.763 | 102.445 | 1.209 | 101.682 |
| B | | | 1.517 | **100.928** |

Steps: 100.000 + 1.632 = 101.632. 101.632 − 0.845 = 100.787. 100.787 + 2.104 = 102.891. 102.891 − 1.209 = 101.682. 101.682 + 0.763 = 102.445. 102.445 − 1.517 = 100.928.

Arithmetic check: sum of BS = 1.632 + 2.104 + 0.763 = 4.499. Sum of FS = 0.845 + 1.209 + 1.517 = 3.571. 4.499 − 3.571 = **0.928**. Last − first = 100.928 − 100.000 = **0.928**. They match, so the sums are right.
