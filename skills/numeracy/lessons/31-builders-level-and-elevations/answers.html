Setting heights with a builder's level

Carry an elevation from a benchmark with backsights and foresights, fill in a level book and check it, and work out the rod reading, cut or fill for a footing, a slab or a pipe.

Task 1 (level 1-2)

a) HI = 25.000 + 1.384 = 26.384 b) P1: 26.384 − 0.912 = 25.472. P2: 26.384 − 1.655 = 24.729. P3: 26.384 − 2.073 = 24.311. P4: 26.384 − 1.240 = 25.144 c) P1 is the highest (smallest rod reading, 0.912). P3 is the lowest (biggest rod reading, 2.073).

Task 2 (level 2)

a) 101.250 − 100.150 = 1.100 b) 101.250 − 99.450 = 1.800 c) 101.250 − 98.875 = 2.375 d) The form is at 101.250 − 1.180 = 100.070. It should be at 100.150. 100.150 − 100.070 = 0.080. The form is too low by 80 mm. (The rod reads more than 1.100, and a bigger reading means a lower point.)

Task 3 (level 2)

Point BS HI FS Elevation
BM1 1.632 101.632 100.000
TP1 2.104 102.891 0.845 100.787
TP2 0.763 102.445 1.209 101.682
B 1.517 100.928

Steps: 100.000 + 1.632 = 101.632. 101.632 − 0.845 = 100.787. 100.787 + 2.104 = 102.891. 102.891 − 1.209 = 101.682. 101.682 + 0.763 = 102.445. 102.445 − 1.517 = 100.928.

Arithmetic check: sum of BS = 1.632 + 2.104 + 0.763 = 4.499. Sum of FS = 0.845 + 1.209 + 1.517 = 3.571. 4.499 − 3.571 = 0.928. Last − first = 100.928 − 100.000 = 0.928. They match, so the sums are right.

Task 4 (level 2-3)

a) HI = 51.200 + 1.440 = 52.640 b) and c)

Task 5 (level 3)

a) Sum of BS = 1.215 + 1.876 + 1.402 = 4.493. Sum of FS = 2.340 + 0.958 + 1.633 = 4.931. 4.493 − 4.931 = −0.438. Last − first as written = 29.662 − 30.000 = −0.338. They differ by 0.100. The check fails. b) Recheck each line. BM: 30.000 + 1.215 = 31.215, right. TP1: 31.215 − 2.340 = 28.875, right. 28.875 + 1.876 = 30.751, right. TP2: 30.751 − 0.958 = 29.793, but the book says 29.893. The TP2 elevation is 0.100 too high, and the HI and the elevation of C after it carry the same mistake. c) TP2 HI = 29.793 + 1.402 = 31.195. C = 31.195 − 1.633 = 29.562. Check: 29.562 − 30.000 = −0.438, which matches 4.493 − 4.931. d) Open task. A good note:

  • says the level book had a subtraction error at TP2: 30.751 − 0.958 is 29.793, not 29.893
  • says the error carried forward, so point C was booked 100 mm too high
  • gives the corrected elevation of C, 29.562, and says the arithmetic check now passes
  • asks that nothing set from the old number be built until it is rechecked
  • is short and uses the numbers
