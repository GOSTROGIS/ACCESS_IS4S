# Illustration record

`learning-day.png` is an original AI-generated illustration created for this
IS4S activity on 16 November 2026 using the available OpenAI image generation
tool. It is not an Artcraft asset or a photograph of an actual ACCESS event.

Brief: a fictional Community Learning Day in a bright carpentry training room;
three adults discuss a wooden birdhouse prototype, with a pencil sketch, tape
measure, wood offcuts and closed laptop. Natural daylight, cream/charcoal with
red and gold accents, no readable text, logos, culturally specific motifs,
measurements, active machinery or tool operation.

Learning purpose: compare an evocative illustration with an explicit SVG plan,
then distinguish an image from evidence. The same image appears in the brief,
storyboard and evidence review so learners can revisit its limitations. Alt
text and a visible generated-image caption are included in the studio.

`diagram.js` draws the room plans from the learner's choices. Those plans are
original schematic examples, not measurements, approved layouts or imported
third-party diagrams. The notice SVG is generated locally by `studio.js` from
the supplied fictional event facts.

`prototype-detail.png` was generated with the same tool on the same date. It
shows an unfinished timber birdhouse, pencil sketch and tape measure on a
clean workshop bench. It provides a close-up alternative in the storyboard,
so learners can compare a setting shot with a detail shot. It is illustrative,
not a construction plan or evidence that the pictured object was built.
