Site builder: teaching and reflection

Public teaching guidance. This is a digital-skills activity, not construction safety training or a qualified site-layout review.

Before starting

Allow 30–45 minutes. Learners need basic number entry and file saving. Explain metres, east/north coordinates and the 0–8 hour practice day. A negative east coordinate means west; a negative north coordinate means south. Positions refer to the object's centre. All objects sit on level ground.

Activity guidance

  1. Ask learners to read the container's overall dimensions in the source panel. Rotation changes which direction its length points; it does not change its length. Compare 0° and 90°.
  2. The challenge's container O1 and cabin O2 share space from hour 2 until hour 4. A valid spatial solution moves the cabin to east 12 m, north 0 m. Check all hours again. This only resolves the modeled rectangle overlap.
  3. Changing O2 to start 4, end 8 removes their time overlap. At hour 3 only O1 is present; at hour 4 only O2 is present. Discuss the limitation: a real handover may need setup time, removal work and supervisor approval. End and start touching is allowed by this exercise, not guaranteed safe on site.
  4. Ask learners to export a before and after plan, reopen the saved file and verify the object count, position and times. A successful download is not evidence until the saved content has been checked.

Evidence and feedback

  • Can the learner locate and select an object without relying on dragging?
  • Can they explain position, rotation, dimension and time as different properties?
  • Can they identify the overlap's objects and time window, make one justified change and test it?
  • Can they name an unchecked concern such as access, clearance, ground bearing, moving equipment or local regulations?
  • Can they save, reopen and explain a version to a partner?

Support: pair a reader and operator, use whole-number times, and start with two objects. Extension: add a third object to test whether solving one overlap creates another. Compare spatial separation and scheduling separation.

How the model works

The 3D display uses actual Slipcurve parametric models. The learning check uses each catalogue object's overall rectangular footprint, rotated in plan, and compares shared time intervals. Fine model details may extend outside those rectangles. It is deliberately not the full Slipcurve clash engine, and does not test 3D mesh intersections or clearance envelopes. Top view, table and text feedback remain usable if 3D is unavailable.
