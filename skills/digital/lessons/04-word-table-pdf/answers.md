# Build a table in Word and save a PDF

## Task 1 (level 1)

- Five tools with serial numbers and inspection dates: **yes**. Each tool has the same three pieces of information, so they line up in columns.
- A two-paragraph note to the night crew: **no**. It is sentences, not rows and columns. Write it as paragraphs.
- A weekly crew schedule: **yes**. Days across and names or crews down make a grid.

## Task 2 (level 2)

Answer: a 3-column, 10-row table. Row 1: `Skill`, `What it means`, `Example in my trade`. Rows 2 to 10: Adaptability, Collaboration, Communication, Creativity and innovation, Digital, Numeracy, Problem solving, Reading, Writing (the order on the page).

A good response:

- has all nine skills, spelled as on the canada.ca page
- puts a short meaning from the page in column 2. Two examples taken from the page: Digital is "your ability to use digital technology and tools to find, manage, apply, create and share information and content". Communication is "your ability to receive, understand, consider, and share information and ideas through speaking, listening, and interacting with others."
- gives a real example from the learner's trade in column 3, such as "Numeracy: work out stair rise and run" for carpentry or "Reading: read a welding procedure specification" for welding
- has no empty rows

Level 2 because the learner pulls information from a web page and organizes it in a new structure.

## Task 3 (level 1)

Answer: **Header Row** is ticked. The Accessibility pane shows no table issues, or the learner fixed what it found (for example, removed an empty row or unmerged cells).

## Task 4 (level 2)

Answer: under "Taking a tool" is a 4-column, 5-row table. Row 1: `Tool number`, `Name`, `Date out`, `Date back`. Column 1, rows 2 to 5: T-01, T-02, T-03, T-04. The other cells are left for the crew. Saved as `tool-crib-procedure_[initials]_v2`, and `v1` still exists.

Steps: open `v1`, save a copy as `v2` before editing, confirm `v2` is open, then click at the end of the "Taking a tool" paragraph, press Enter, **Insert** > **Table** 4 by 5, type the headings and tool numbers using Tab, tick **Header Row**, then **File** > **Save As** (or **Save a Copy**) with `v2`.

Note: empty cells for the crew to fill in are fine in a form. The rule against blank cells is about whole empty rows or columns.

## Task 5 (level 2)

Answer: a PDF named like `tool-crib-procedure_[initials]_v2.pdf` in the same folder as the Word file.

A good response names a real check and its result, for example: "I checked the table. All four columns fit on the page and T-01 to T-04 are there." or "The date on the title page was wrong. I fixed it in Word and saved a new PDF."

## Task 6 (level 2)

Answer: a 3-column, 4-row table:

| Item | Qty | Unit |
|---|---|---|
| 2x4 stud, 8 ft | 48 | each |
| Drywall screws | 6 | box |
| Construction adhesive | 12 | tube |

Steps: type each line pressing Tab between parts and Enter at the end. Select all four lines. **Insert** > **Table** > **Convert Text to Table** > **OK**. Tick **Header Row**.

If the table comes out with one column, the parts were separated with spaces instead of tabs.

## Check yourself

1. It tells Word and screen readers that the first row holds the column names, so a screen reader can say "Qty" before reading "48".
2. Tab. Shift + Tab goes back.
3. A PDF usually preserves the page layout, and the reader does not need Word. Still check its layout and accessibility before sharing.
4. To make changes later. A PDF is a reading copy and is not meant for editing.
5. Any of: every page is there, every row of the table is there, nothing is cut off at the edge, the title and date are right.
