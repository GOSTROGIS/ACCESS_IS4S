# Build a table in Word and save a PDF

Steps checked in Word for Microsoft 365 on Windows 11, 2026-11-06.

## Why this matters on the job

Sign-out sheets, crew lists, inspection checklists and material orders are all tables. When you send one to a supplier, an owner or a WorkSafeBC officer, a PDF usually preserves the page layout better than an editable Word file, and the reader does not need Word. Check the PDF before sharing it; a PDF is not automatically accessible or protected from editing. You keep the Word file so you can still edit it.

## Key ideas

### When to use a table

Use a table for information that lines up in rows and columns, such as "tool number, name, date out, date back". Microsoft's accessibility advice is to keep tables simple:

- one header row with a name for every column
- no merged or split cells, and no table inside a table
- no completely empty rows or columns

Screen readers count cells to keep track of where they are, so merged cells and blank rows confuse them.

### Making a table

1. Click where the table should go.
2. **Insert** > **Table**, then move the pointer over the grid to pick the number of columns and rows, and click.
3. For a bigger table, choose **Insert** > **Table** > **Insert Table** and type the numbers.
4. Type in the first cell. Press **Tab** to move to the next cell, and **Shift + Tab** to go back.

If the text is already typed with tabs between the parts, select it and choose **Insert** > **Table** > **Convert Text to Table**.

### The header row

When the cursor is in a table, two extra tabs appear on the ribbon for table design and table layout. On the table **Design** tab, in **Table Style Options**, tick **Header Row**. This tells Word and screen readers that the first row holds the column names.

### Saving a PDF copy

1. Save the Word file first (Ctrl + S).
2. Select **File** > **Save a Copy**. (For a file never saved before, **File** > **Save As** also works.)
3. Select **Browse** and choose the folder.
4. In the file type list, choose **PDF**.
5. Select **Save**.

Then open the PDF and check every page: all rows there, nothing cut off at the edge, headings correct. A PDF can still be opened and changed in some programs, including Word, so it is a reading copy, not a lock.

### Worked example

A crew lead at the fictional Riverbend Builders needs a sign-out table for three ladders.

1. In the procedure document, she clicks below the "Taking a tool" paragraph.
2. **Insert** > **Table**, 3 columns by 4 rows.
3. She types `Tool number`, Tab, `Name`, Tab, `Date out` in row 1, then the ladder numbers L-01, L-02 and L-03 down the first column.
4. On the table **Design** tab she ticks **Header Row**.
5. She saves (Ctrl + S), then **File** > **Save a Copy**, chooses **PDF**, and saves `ladder-sign-out_riverbend_2026-11-06_v1.pdf`.
6. She opens the PDF and checks that all four rows are there.
