# Build a table in Word and save a PDF

ACCESS Indigenous Skills4Success · Digital · Lesson plan

| Session | Total length |
|---|---|
| Digital 4 | 60 min |

## Opening (3 min)

Welcome learners back. Hook: show a tool sign-out sheet that was emailed as a Word file and opened on a phone with the columns all broken. Then show the same sheet as a PDF on the same phone. Ask which one the supplier or the safety officer would rather get. Today: tables that line up, and PDFs that look the same everywhere.

## Objective (2 min)

By the end of the session learners will be able to:

- decide when information belongs in a table (Use digital information)
- insert a table, fill it with Tab, set a header row and convert tabbed text to a table (Use common digital tools to complete tasks: use software for a purpose, for example Word)
- save and check a PDF copy while keeping the editable Word file (Use common digital tools to complete tasks, Use digital information: store and organize digital information in a logical way)

Complexity: level 2, with Tasks 1 and 3 at level 1.

## Pre-assessment (2 min)

1. Have you ever filled in a sign-out sheet or a crew list? What columns did it have?
2. What is a PDF, and when have you opened one?

## Learning tasks (45 min)

| Step | Instructor activities | Learner activities | Resources | Time |
|---|---|---|---|---|
| 1.1 | Explain when to use a table and Microsoft's three rules for simple tables. | 1.1 Complete Task 1 and share one answer. | Learner page | 5 min |
| 1.2 | Model the worked example: **Insert** > **Table**, Tab between cells, **Header Row** on the table Design tab. | 1.2 Watch and repeat the first two steps on a blank page. | Projector, Word | 7 min |
| 2.1 | Show the canada.ca page and where the nine skills are listed. Circulate while learners build the table. | 2.1 Complete Task 2. | canada.ca page, Word | 15 min |
| 2.2 | Demonstrate **Review** > **Check Accessibility** on a table with a merged cell, so learners see a warning. | 2.2 Complete Task 3. | Word | 6 min |
| 3.1 | Demonstrate Ctrl + S, then **File** > **Save a Copy** > **Browse** > **PDF** > **Save**. | 3.1 Complete Task 4, then the saving part of Task 5. | Lesson 3 file, Word | 8 min |
| 3.2 | Open a PDF and show what to check: every page, every row, nothing cut off. | 3.2 Finish Task 5. Early finishers do Task 6. | PDF viewer | 4 min |

## Post-assessment (5 min)

1. Show me your PDF. Where is the Word file it came from?
2. Point to the header row in your table. Why did you tick **Header Row**?
3. A co-worker merged two cells so a heading spans the whole table. What problem does that cause, and what could they do instead?

## Summary (3 min)

During this session we covered:

- when information belongs in a table
- inserting a table and moving between cells with Tab
- the header row and keeping tables simple for screen readers
- converting tabbed text to a table
- saving a PDF copy, checking it, and keeping the editable file

Time check: 3 + 2 + 2 + 45 + 5 + 3 = 60 min.

## Notes for the instructor

- The ESAF table task sent learners to Job Bank Essential Skills profiles for Metal Fabricators (NOC 7263), Welders (NOC 7265) and Pipefitters (NOC 7252). Those old page addresses are not used here. Task 2 keeps the idea (a table of skills for your trade) and uses the current Skills for Success page.

- The ribbon tab names for tables can show as **Table Design** and **Layout** on some screens. Point to the tabs that appear when the cursor is in the table.
