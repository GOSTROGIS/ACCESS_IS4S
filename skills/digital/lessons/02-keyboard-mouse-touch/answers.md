# Keyboard, mouse and touch screen

## Task 1 (level 1)

Open answer. A good response names one real change, for example "raised the chair so my forearms are level", "moved the screen back to arm's length", "moved the mouse next to the keyboard" or "put my feet on a footrest". The learner can say which posture point the change fixes.

## Task 2 (level 1)

Answer: a saved document `shortcut-practice_[initials]_v1` with the line `Bring the 25 ft tape and the chalk line.` appearing twice (the original and one paste, because the second paste was undone).

Steps: Ctrl + A selects the line. Ctrl + C copies. Press Ctrl + End to move to the end of the line, press Enter, Ctrl + V. Enter, Ctrl + V again. Ctrl + Z removes the last paste. Ctrl + S, type the name, Save.

## Task 3 (level 1)

Answer: 14 accented letters.

Steps: count in order. Thérèse (2), Mädchen (1), François (1), résumé (2), François (1), Thérèse (2), résumé (2), Voilà (1), résumé (2). 2 + 1 + 1 + 2 + 1 + 2 + 2 + 1 + 2 = 14.

Keys used: é with Ctrl + ', è and à with Ctrl + `, ä with Ctrl + Shift + :, ç with Ctrl + , then c.

## Task 4 (level 2)

Answer: `Bevel: 37½° on both plates`

Steps: type `Bevel: 37`, then a space, then `00BD`, press Alt + X (½ appears), then delete the space before ½. Straight after the ½, type `00B0` and press Alt + X (° appears). Type ` on both plates`.

Level 2 because the learner has to notice that the digits 3 and 7 would join the code and plan around it.

## Task 5 (level 1)

Answer: two-finger slide scrolls, pinch or spread zooms, press and hold on a touch screen (or two-finger tap on a touchpad) opens the extra menu. A good response names each gesture with the action it did.

## Task 6 (level 2)

Open answer. Record the learner's own words and mistakes for two minutes. A good response is honest numbers and one thing to try next time, such as "keep eyes on the passage". There is no pass mark. The aim is to beat your own count later.

## Check yourself

1. Straight, in a neutral position, with fingertips at the height of the middle row of keys. Not resting on the desk edge while typing.
2. Undo. It reverses the last action.
3. Press Ctrl + ' (apostrophe) together, let go, then type e.
4. Press and hold the item.
5. Stop, change position or stretch, and take a short break. If the pain comes back, tell your instructor or supervisor.
