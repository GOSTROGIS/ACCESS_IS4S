Format a work document in Word

Use the Home tab, heading styles, line spacing and a title page to turn plain text into a workplace procedure people can read and follow.

  • Learner
  • Instructor🔒 (instructor code)
  • Answers🔒 (instructor code)
  • Level: 1-2
  • Time: 90 min
  • Components: Use common digital tools to complete tasks; Use digital information

Task 1 (level 1)

Answer: (a) Font, (b) Styles, (c) Paragraph, (d) Editing.

Steps: bold is a font setting. Headings are styles. Line spacing belongs to the paragraph. Replace is an editing tool (Ctrl + H opens it from anywhere).

Task 2 (level 1)

Answer: Tool Crib Sign-Out shows as Heading 1. Taking a tool, Checking a tool and Returning a tool show as Heading 2.

Steps: click in the title line, Home > Styles > Heading 1 (or Ctrl + Alt + 1). Click in each section heading, Heading 2 (or Ctrl + Alt + 2).

Check: click in each heading. The matching style is highlighted in the Styles gallery.

Task 3 (level 2)

Answer: the four body paragraphs (the three procedure paragraphs and the fictional-company line) have 1.5 line spacing and 6 pt after. No empty paragraphs remain between them.

Steps: select the body paragraphs (hold Ctrl to add each one, or do one at a time). Home > Line and Paragraph Spacing > Line Spacing Options. Line spacing: 1.5 lines. After: 6 pt. OK. Delete any blank lines with Backspace or Delete.

Level 2 because the learner has to select only the body text and leave the headings alone.

Task 4 (level 1)

Answer: Do not take a damaged tool. is bold and the rest of the paragraph is not.

Steps: select the sentence, press Ctrl + B (or Bold in the Font group).

Task 5 (level 2)

Answer: the return line reads Return tools by 3:00 p.m. Find shows 11 results for tool.

Steps: Ctrl + H, Find what 3:30 p.m., Replace with 3:00 p.m., Replace All (1 replacement). Ctrl + F, type tool. The Navigation pane counts every match.

Count, line by line (Find matches upper and lower case and parts of words): Tool Crib Sign-Out (1), Taking a tool (1), Every hand tool, power tool, take a tool (3), Checking a tool (1), Check the tool, damaged tool (2), Returning a tool (1), Return tools (1), each tool (1). 1 + 1 + 3 + 1 + 2 + 1 + 1 + 1 = 11.

If the learner typed the text differently, accept the count Word shows and ask them to point to each match.

Task 6 (level 2)

Answer: page 1 holds four centred lines (title, prepared by, ACCESS Indigenous Skills4Success, Digital, date). The procedure starts at the top of page 2.

Steps: Ctrl + Home to go to the start. Type the four lines, pressing Enter after each. Select the four lines, Ctrl + E. Click at the end of the date line, Ctrl + Enter. If the four new lines took the Heading 1 style from the title, change them to Normal (Ctrl + Shift + N) before centring.

Task 7 (level 1)

Answer: Portrait (upright) suits a one-page procedure, because the text is a list of short paragraphs and reads top to bottom. A sideways page suits wide tables, schedules or drawings.

Task 8 (level 2)

Answer: the learner reads the Accessibility pane and either fixes each item or records "no issues found". The file is saved as tool-crib-procedure_[initials]_v1 in the Riverbend job folder.

A good response: names what the checker listed (for example, a heading order warning if a heading level was skipped), fixes it, runs the check again, and saves with the Lesson 1 naming pattern.

Check yourself

  1. Heading 2 is a saved style: every Heading 2 looks the same, changes together when the style is modified, and tells screen readers it is a heading. Hand formatting only changes how that one line looks.
  2. Ctrl + 2.
  3. Space After stays the same when someone edits the document. Extra blank lines shift, and they leave empty paragraphs that screen readers announce.
  4. Layout > Orientation.
  5. The Review tab.
