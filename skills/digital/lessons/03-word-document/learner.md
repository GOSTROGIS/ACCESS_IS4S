# Format a work document in Word

Steps checked in Word for Microsoft 365 on Windows 11, 2026-11-06. Word for the web, Mac and tablets have the same tabs, but some buttons sit in different places.

## Why this matters on the job

Contractors in BC write safe work procedures, toolbox talk notes and site rules in Word. A procedure that looks like one long block of text gets skimmed and ignored. Clear headings, even spacing and bold where it matters make a document people will actually follow, and a screen reader can read it aloud to someone who needs that.

## Key ideas

### The ribbon and the tabs

Across the top of Word is the **ribbon**, a band of buttons split into tabs: **File**, **Home**, **Insert**, **Design**, **Layout**, **References**, **Mailings**, **Review**, **View**. The old Word menus (File, Edit, Format) from ACCESS's first computer lessons are gone. Most everyday tools are on the **Home** tab:

| Group on the Home tab | Use it to |
|---|---|
| Font | Change font, size, **bold**, *italic*, underline, colour |
| Paragraph | Line up text, make lists, set line spacing |
| Styles | Apply headings and body text styles in one click |
| Editing | Find and replace words |

Rest the pointer on any button to see its name.

### Styles, not hand formatting

A **style** is a saved set of formatting. Select a line and choose **Heading 1** in the **Styles** gallery on the Home tab, and it gets the heading font, size and spacing in one click. Use **Heading 1** for the document title, **Heading 2** for section headings, and **Normal** for body text. Styles keep every heading the same, and screen readers use them to jump between sections. Shortcut: Ctrl + Alt + 1 for Heading 1, Ctrl + Alt + 2 for Heading 2.

### Line spacing and space between paragraphs

- **Line spacing** is the gap between lines inside a paragraph. Shortcuts: Ctrl + 1 single, Ctrl + 5 1.5 lines, Ctrl + 2 double.
- **Space before and after** is the gap between paragraphs.

To set both: select the paragraphs, go to **Home** > **Line and Paragraph Spacing**, choose **Line Spacing Options**, pick the **Line spacing** and set **Before** and **After**, then **OK**.

When a supervisor asks for a document "double-spaced", change the line spacing. Do not press Enter twice between lines. Extra blank lines move around when someone edits the document, and the spacing setting does not.

### Other tools you will use today

| To do this | Use |
|---|---|
| Centre a line | Ctrl + E |
| Start a new page | Ctrl + Enter (page break) |
| Find a word | Ctrl + F |
| Find and replace | Ctrl + H |
| Turn the page sideways or upright | **Layout** > **Orientation**, then `Landscape` or `Portrait` |
| Check spelling | **Review** tab |
| Check that others can read it | **Review** > **Check Accessibility** |

### Worked example

Mei has the sentence `Lockout before you clear a jam` typed in a procedure. She wants it to be a section heading.

1. She clicks anywhere in the line.
2. On the **Home** tab, in **Styles**, she chooses **Heading 2**.
3. The line changes size and colour, and gets space above it. She did not touch the font box.
4. Later the safety coordinator wants all section headings larger. Mei right-clicks **Heading 2** in the Styles gallery and chooses **Modify**. Every Heading 2 in the document changes at once.

## Practice

Open a new blank Word document. Type or paste this text exactly. It is for a fictional contractor.

> Tool Crib Sign-Out
>
> Taking a tool
>
> Every hand tool and power tool in the crib has a number. Before you take a tool, write the number, your name and the date on the sign-out sheet.
>
> Checking a tool
>
> Check the tool before you leave the crib. Look for a cracked handle, a frayed cord or a missing guard. Do not take a damaged tool. Tag it and tell the crib attendant.
>
> Returning a tool
>
> Return tools by 3:30 p.m. Wipe them down and coil cords loosely. The attendant checks each tool back in and initials the sheet.
>
> This procedure is for Riverbend Builders, a fictional company used for training.

**Task 1** (level 1) Name the Home tab group you would use to: (a) make text bold, (b) apply Heading 1, (c) set 1.5 line spacing, (d) replace one word with another.

**Task 2** (level 1) Apply **Heading 1** to `Tool Crib Sign-Out`. Apply **Heading 2** to the three section headings.

**Task 3** (level 2) Select the four body paragraphs (not the headings). Set line spacing to 1.5 lines and 6 pt **After**. Delete any blank lines you typed between paragraphs.

**Task 4** (level 1) Make the sentence `Do not take a damaged tool.` bold.

**Task 5** (level 2) The return time has changed. Use Find and Replace (Ctrl + H) to change `3:30 p.m.` to `3:00 p.m.` Then use Find (Ctrl + F) to count matches for `tool`, including `tools`, with case matching and whole-word matching off. Do this before adding the title page in Task 6. Write the count Word shows.

_______

**Task 6** (level 2) Make a title page. Click at the very start of the document. Type these four lines, each on its own line: `Tool Crib Sign-Out`, `Prepared by [your name]`, `ACCESS Indigenous Skills4Success, Digital`, today's date. Centre the four lines with Ctrl + E. Then press Ctrl + Enter so the procedure starts on page 2.

**Task 7** (level 1) Turn the page sideways with **Layout** > **Orientation** > `Landscape`. Look at it, then change it back to `Portrait`. Write which one suits a one-page procedure and why.

**Task 8** (level 2) Run **Review** > **Check Accessibility**. Read what it finds. Fix anything it lists, or write "no issues found". Save the document as `tool-crib-procedure_[initials]_v1` in your Riverbend job folder from Lesson 1.
