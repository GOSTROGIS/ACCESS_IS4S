## Task 3 (level 2)

Answer: about 800 tokens.

Steps: 100 tokens is about 75 words, so tokens = words × 100 ÷ 75. Multiply and divide from left to right (BEDMAS): 600 × 100 = 60 000, then 60 000 ÷ 75 = 800.

Another correct method: 600 ÷ 75 = 8 groups of 75 words, and 8 × 100 = 800 tokens. Accept "about 800". It is an estimate for English text.

## Check yourself

1. It was trained on lots of text and learned patterns. It writes an answer by predicting the next word (token), then the next, until it is done.
2. The model is the trained engine that predicts text. The app is the website or phone app around it, which can add tools such as web search, file reading and memory.
3. It picks likely words, and likely is not the same as true. It can also invent sources or numbers and present them smoothly.
4. Web search lets the app look up current pages and show links. It does not guarantee the answer reads those pages correctly, so you still open the link and check.
5. Ask, name the claim, find the official source, compare, then use it, fix it or drop it and write where you checked.
