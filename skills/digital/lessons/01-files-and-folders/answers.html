Save, name and find your files

Make a folder, give a file a name the next person can understand, save it in the right place and find it again.

  • Learner
  • Instructor🔒 (instructor code)
  • Answers🔒 (instructor code)
  • Level: 1
  • Time: 60 min
  • Components: Use digital devices including computers, tablets, smart phones, and other handheld devices; Use digital information

Task 1 (level 1)

Word Meaning
file One saved piece of work
folder A place that holds files
device The equipment you hold or sit at
app The program you use to do a task

Steps: read each meaning and ask "is this the equipment, the program, the saved work or the place it is kept?"

Task 2 (level 1)

Answer: a folder IS4S-digital-[initials] with a folder Riverbend job inside it, in the practice location.

Steps: Windows logo key + E opens File Explorer. Go to the practice location. Select New > Folder, type the name, press Enter. Double-click the new folder, then repeat for Riverbend job.

Check: the learner can open IS4S-digital-[initials] and see Riverbend job inside it.

Task 3 (level 1)

Answer: a name such as tool-check_riverbend-job_2026-11-06_v1, saved in ...\IS4S-digital-[initials]\Riverbend job.

A good response:

  • says what the file is (tool check), which job (Riverbend) and the date, year first
  • ends in v1
  • uses none of < > : " / \ | ? *
  • gives the location as the folder path, separate from the name

Task 4 (level 1)

Answer: the file opens and shows Tool check: 2 tape measures, 1 chalk line, 1 speed square.

Steps: close Word. Open File Explorer, go to the Riverbend job folder (or the practice location), type part of the name such as tool-check in the search box, open the result, read the line.

Task 5 (level 2)

Answer: two files, ..._v1 without the knife and ..._v2 with 1 utility knife. The v2 file is the one with the knife.

Steps: open v1, add the item, then File > Save As (or File > Save a Copy if AutoSave is on) and change the end of the name to v2. Close. Open each file and read the list.

Level 2 because the learner has to keep two versions apart and check content, not only the name.

Task 6 (level 1)

Sample answers (any name with what, which job and when is correct):

  • Document1 → site-notes_riverbend-job_2026-11-06_v1. The old name says nothing about the content.
  • final final NEW → material-list_riverbend-job_2026-11-06_v3. "Final" and "new" stop being true the next time it changes. A version number does not.
  • drawings: unit 4? → drawings_unit-4_2026-11-06_v1. Windows does not allow : or ? in a name.

Check yourself

  1. The name says what the file is. The location says where it is saved (the folder path). You need both to find it.
  2. Year first (2026-11-06) makes files sort in date order when the folder is sorted by name.
  3. No. A blue cloud outline means online only, and online-only files cannot be opened without the internet. Before going offline, right-click it and choose Always keep on this device, or open it once while connected.
  4. Windows logo key + E.
  5. Saving as v2 keeps v1, so you can go back if the change was wrong, and anyone can see which copy is newer.
