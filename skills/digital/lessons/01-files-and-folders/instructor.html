Save, name and find your files

Make a folder, give a file a name the next person can understand, save it in the right place and find it again.

  • Learner
  • Instructor🔒 (instructor code)
  • Answers🔒 (instructor code)
  • Level: 1
  • Time: 60 min
  • Components: Use digital devices including computers, tablets, smart phones, and other handheld devices; Use digital information

ACCESS Indigenous Skills4Success · Digital · Lesson plan

Session Total length
Digital 1 60 min

Opening (3 min)

Welcome learners and thank them for coming. Hook: "You finish a material count at the end of a shift. The next morning the foreman asks for it. Where is it?" Ask who has ever lost a file, a photo or a form on a phone or computer. Most hands go up. Today we fix that with three habits: a folder for the job, a name that explains itself, and a check that the file opens again.

Objective (2 min)

By the end of the session learners will be able to:

  • name the device, app, file and folder they are using (Use digital devices including computers, tablets, smart phones, and other handheld devices)
  • make folders, save a file with a clear name and version, and find it again by search (Use digital information: store and organize digital information in a logical way using files, folders and labels)
  • read the OneDrive status icons and say whether a file will open without the internet (Use digital information)

Complexity: level 1, with Task 5 at level 2.

Pre-assessment (3 min)

  1. Where do you usually save something you make on a computer or phone?
  2. If a file is called "Document1", what would you need to do to know what is in it?

Learning tasks (44 min)

Step Instructor activities Learner activities Resources Time
1.1 Explain device, app, file and folder with the job-box comparison. Point to each on the projected screen. 1.1 Listen, then complete Task 1 (match the four words). Learner page, projector 5 min
1.2 Model the worked example: a folder for the Riverbend job and the name material-request_riverbend_2026-11-06_v1. Show the characters Windows does not allow. 1.2 Watch. Say out loud what each part of the example name tells a reader. Projector, Word, File Explorer 6 min
2.1 Show the class practice location. Demonstrate Windows logo key + E, then New > Folder. Circulate. 2.1 Complete Task 2: make the two folders. One computer per learner 8 min
2.2 Demonstrate File > Save As, browse to the folder, type the name, Save. If the file is in OneDrive with AutoSave on, show File > Save a Copy before editing to protect the original. Confirm the new file name before making the change. 2.2 Complete Task 3. Write the name and the location. Word 10 min
3.1 Demonstrate the File Explorer search box. Explain the three OneDrive icons on the board. 3.1 Complete Tasks 4 and 5: find the file, make v2, open both and compare. File Explorer, OneDrive if used 10 min
3.2 Write the three poor names on the board. Take answers from the group. 3.2 Complete Task 6. Share one improved name. Whiteboard 5 min

Post-assessment (5 min)

  1. Show me your v1 and v2 files and tell me which one is newer and how you know.
  2. A co-worker saved drawings: unit 4?. Why will Windows refuse that name, and what would you call it?
  3. A file shows a blue cloud outline. The site trailer has no internet. What happens when you try to open it, and what could you have done before leaving the office?

Summary (3 min)

During this session we covered:

  • device, app, file and folder
  • the difference between a file name and its location
  • file names with the job, the date (year first) and a version number
  • the characters Windows and OneDrive do not allow in names
  • finding a file with File Explorer search
  • the OneDrive icons for online-only and downloaded files

Time check: 3 + 2 + 3 + 44 + 5 + 3 = 60 min.

Notes for the instructor

  • Set up the practice location before class and test that learners can save there. On shared computers, ask learners to delete their practice folders at the end or show them where the folders will be cleared.
  • Learners who already manage files well can help a partner, then try Task 5 with a second change and v3.
  • The OneDrive icons only appear if the computer is signed in to OneDrive. If it is not, teach the icons from the table and leave the live check for later.
  • The Digital chapter's Control one action and check its effect and the practice desk give more save-and-reopen practice.

Evidence to check

Observe the learner reopen both files and compare their contents, not only their names. Record whether the original stayed unchanged.
