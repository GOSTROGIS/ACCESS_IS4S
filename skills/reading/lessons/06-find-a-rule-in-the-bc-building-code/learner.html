Find a rule in the BC Building Code

Use the edition, the index and the numbering system of the BC Building Code 2024 to find the exact rule that applies, and read it word by word.

  • Learner
  • Instructor
  • Answers
  • Level: 1-3
  • Time: 90 min
  • Components: Identify the task that requires you to read; Identify the information; Make connections between different parts of the document(s); Evaluate the document(s)

Why this matters on the job

On a house, a small building or a renovation in BC, the BC Building Code sets the minimum rules: how high a stair can go, what goes under floor tile, how far a handrail can stick out. A foreman may say "Code says…" and you need to check it yourself. The Code is thousands of pages, so nobody reads it front to back. You find a rule by its number and by the index, and then you read it very closely.

Key ideas

1. Use the current edition. The BC Building Code 2024 came into effect on March 8, 2024. It applies to projects with building permits applied for after that date. It is based on the National Building Code of Canada 2020. The Province posts it as a free PDF, and says that the PDF does not include every later update. Check the revisions and bulletins on the same web page.

BC Building Code 2024 page: https://www2.gov.bc.ca/gov/content/industry/construction-industry/building-codes-standards/bc-codes/2024-bc-codes

2. How the Code is organized.

Part of the Code What it holds
Division A Compliance, objectives and functional statements
Division B Acceptable solutions: the technical rules
Division C Administrative provisions
Division B, Part 9 Housing and Small Buildings. Most residential work is here. It is in Volume 2.
Index At the back of each volume. Topics in alphabetical order, with Code numbers.

3. How a Code number works. Each extra number goes one level deeper.

Level Example What it is
Part 9 Housing and Small Buildings
Section 9.30. Flooring
Subsection 9.30.2. Panel-Type Underlay
Article 9.30.2.1. Required Underlay
Sentence 9.30.2.1.(3) one numbered rule in that article
Clause (a), (b) … one part of a sentence
Subclause (i), (ii) … one part of a clause

4. Words in italics have a special meaning. Part 9 says: "Words in italics are defined in Article 1.4.1.2. of Division A." If a word is in italics, look it up there. Do not guess. In the index, "1.4.1.2.[A]" means Article 1.4.1.2. of Division A.

5. "Shall" means must. BC's Interpretation Act says "shall" is to be read as imperative, and "may" as permissive. Watch the limit words too: not less than (at least), not more than (no more than), except, only.

6. Tables and notes. Under each table, the Code tells you which rule uses it, for example "Forming Part of Sentence 9.23.3.4.(1)". Notes to Part 9 are labelled with "A-" and a Code number, such as "Note A-9.8.4." They explain the rule in more detail.

Worked example

Question: Over a lumber subfloor, does ceramic tile need panel-type underlay?

  1. Look in the index under Flooring. It lists "underlay, 9.30.2."
  2. Go to Subsection 9.30.2. Panel-Type Underlay. The first article is 9.30.2.1. Required Underlay.
  3. Read Sentence (1) closely. It says a panel-type underlay shall be provided under resilient flooring, parquet flooring, ceramic tile, felted-synthetic-fibre floor coverings or carpeting laid over lumber subflooring.
  4. Answer: yes. The rule is Sentence 9.30.2.1.(1).

Practice

For Tasks 2 to 7 you need the BC Building Code 2024 PDF open on a phone, tablet or computer. Use the web page in Key idea 1. Part 9 is in Volume 2.

Task 1 (level 1) Name each part of this Code number: 9.8.7.6. And of this one: 9.30.2.1.(3)

Task 2 (level 2) Open the BC Building Code 2024 web page. a) When did the BC Building Code 2024 come into effect? b) The page warns that the PDF may not include everything. What else does it tell you to check?

Task 3 (level 2) Use the index at the back of Volume 2. a) Under "Flooring", what Code number is listed for ceramic tile flooring in houses and small buildings? (Look for the number that starts with 9.30.) b) Under "Ceramic tile", what Code number is listed for installing ceramic tile as an interior wall finish?

Task 4 (level 2) Go to Article 9.30.2.1. Required Underlay. a) Read Sentence (3). Must panel-type underlay go under ceramic tile that is applied with adhesive? b) Which Code number would you quote to your foreman for that rule?

Task 5 (level 2) Go to Article 9.30.2.4. Joints Offset. a) How far must the joints in the underlay be offset from the joints in the subfloor below? b) Is that a minimum or a maximum? Which words tell you?

Task 6 (level 2) Go to Article 9.30.6.1. Substrate, in Subsection 9.30.6. Ceramic Tile. Read Sentence (1). What are the two ways ceramic tile may be set?

Task 7 (level 3) Go to Section 9.8. Stairs, Ramps, Landings, Handrails and Guards. a) In Subsection 9.8.3., find the greatest vertical height allowed for any one flight of stairs. b) Go to Article 9.8.7.6. Projections into Stairs and Ramps. How far can handrails and their supports stick out into the required width of a stair? c) In these articles, some words are in italics, such as ramp and flight. Where do you find what they mean?

Task 8 (level 3) An old ACCESS handout from about 2010 gives a Code number and a rule for the slump of concrete. Your co-worker wants to use it to settle an argument on site today. What would you tell them, and why?

Check yourself

  1. In 9.30.2.1.(3), which number is the Sentence?
  2. Where in the Code do you find the meaning of a word in italics?
  3. What does "shall" mean in a Code rule?
  4. What does "not less than 200 mm" mean in plain words?
  5. Why should you check the revisions page as well as the PDF?
