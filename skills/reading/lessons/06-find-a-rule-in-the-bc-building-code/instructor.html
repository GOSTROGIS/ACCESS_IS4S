Find a rule in the BC Building Code

Use the edition, the index and the numbering system of the BC Building Code 2024 to find the exact rule that applies, and read it word by word.

  • Learner
  • Instructor🔒 (instructor code)
  • Answers🔒 (instructor code)
  • Level: 1-3
  • Time: 90 min
  • Components: Identify the task that requires you to read; Identify the information; Make connections between different parts of the document(s); Evaluate the document(s)

Session 6 of 18 in the Reading lessons · 90 minutes

Opening (5 min)

Welcome learners. Ask: "Who has heard someone on a site say 'Code says…'? Did anyone check?" Hold up a phone and say the whole BC Building Code is free on it. Tell a short story: two carpenters argue about how far a handrail can stick out into a stair. One says 4 inches, one says 6. Neither looks it up. The inspector does. Today learners find the exact rule in less time than the argument takes.

This is session 6 of 18 in the Reading lessons. It runs 90 minutes.

Before the session: check that every learner has a device that can open a large PDF (about 16 MB), or arrange shared devices. Download the PDF in advance in case the internet is slow. If you plan to print pages, read the "Acknowledgements and copyright" section on the BC Building Code 2024 web page first.

Objective (3 min)

By the end of the session, learners will be able to:

  • name the reason for a Code search and the exact thing to find (Identify the task that requires you to read)
  • find a rule using the index and the Code's numbering system (Identify the information)
  • connect a rule to the definitions, tables and notes it relies on (Make connections between different parts of the document(s))
  • judge whether a Code reference is current before relying on it (Evaluate the document(s))

Pre-assessment (5 min)

  1. "What do you think the numbers in '9.30.2.1.(3)' stand for?"
  2. "If you wanted to find a rule about floor tile in a book of thousands of pages, where would you start?"

Post-assessment (9 min)

  1. "Find the article that sets the height of handrails on stairs. Give its number." (Learners can use the index under the stairs entry or Subsection 9.8.7. The article is 9.8.7.4. Height of Handrails.)
  2. "Explain the difference between a Subsection and an Article, using a real number from today."
  3. "A friend sends you a screenshot of a Code rule with no edition on it. What do you check before you trust it?"

Summary (6 min)

During this session we covered:

  • the current BC Building Code 2024, its effective date, and checking revisions
  • Divisions A, B and C, Part 9, and the index
  • the numbering system: Part, Section, Subsection, Article, Sentence, Clause, Subclause
  • words in italics and where they are defined
  • "shall", "may" and limit words such as "not less than"
  • tables, notes, and checking the edition of any Code reference

Total time: 5 + 3 + 5 + 62 + 9 + 6 = 90 minutes.
