Reading · Lesson 02 · Instructor

Break down the question first

Use the question word, the key words and the limit words in a question to know exactly what answer to look for.

  • Learner
  • Instructor
  • Answers
  • Level: 1-2
  • Time: 60 min
  • Components: Identify the task that requires you to read; Identify the information; Understand and apply the information

Session 2 of 10 in the Reading lessons · 60 minutes

Opening (5 min)

Welcome learners back. Ask the class: "Where is the ABM?" Write down the answers you get: "Down the street", "I don't have a bank card", "Why, do you need cash?" Point out that only one of these answers the question that was asked. On a job site the same thing happens with written questions on forms, quizzes and work orders. Today is about reading the question before reading the document.

This is session 2 of 10 in the Reading lessons. It runs 60 minutes.

Objective (2 min)

By the end of the session, learners will be able to:

  • name the kind of answer each question word asks for (Identify the task that requires you to read)
  • underline key words and split a question into given and requested (Identify the information)
  • use limit words and synonyms to give an exact answer from a procedure (Understand and apply the information)

Pre-assessment (5 min)

  1. "What kind of answer does a 'when' question want?" (Listen for both a time and a condition.)
  2. Write on the board: "How often must the lift be checked?" Ask: "Which words are the most important in this question?"

Learning tasks (38 min)

Step Instructor activities Learner activities Resources Time
1.1 Go through the question word table. For each word, ask a learner to make up a job site question that uses it. Make up and say a question for a question word. Learner page, Key idea 1 5 min
1.2 Set Task 1. Fill in the Task 1 table. Learner page, Task 1 3 min
2.1 Model crossing out supporting words on the board with the example in Key idea 2. Set Task 2. Watch, then do Task 2. Read their key words aloud to check they still make sense. Board, Task 2 5 min
2.2 Explain given and requested using the worked example. Set Task 3 in pairs. Do Task 3 with a partner. Learner page, Task 3 8 min
3.1 Explain that documents often use other words. Set Task 4. Do Task 4. Name the matching words. Learner page, Task 4 3 min
3.2 Set Task 5. Ask learners to circle the limit word in the procedure before they answer. Do Task 5. Circle the limit words. Learner page, Task 5 5 min
3.3 Read the St Ives riddle aloud slowly. Let learners try Task 6 before discussing. Do Task 6 and explain their answer. Learner page, Task 6 4 min
3.4 Set Task 7. Discuss how answers that do not match questions cause problems on site. Do Task 7 and share one rewritten answer. Learner page, Task 7 5 min

Post-assessment (6 min)

  1. "In the question 'Which fluid can be used to top up the tank?', what is given and what is requested?"
  2. "The procedure says 'Do not start work if fewer than 2 bars show.' What is the limit, and does 1 bar pass?"
  3. "Your question says 'inspect' but the document says 'check'. What should you do?"

Summary (4 min)

During this session we covered:

  • what each question word asks for
  • key words and supporting words
  • splitting a question into given and requested
  • limit words such as only, both, not and at least
  • documents that use different words from the question

Total time: 5 + 2 + 5 + 38 + 6 + 4 = 60 minutes.
