Read a tender package

Find your way through the drawings, specifications and addenda in a bid package, and use the order of precedence to decide which document wins when they disagree.

Session 21 of 26 in the Reading lessons · 90 minutes

Before the session: learners need a calculator. This lesson follows the drawing lessons 11 to 18. It uses drawing scales from Reading lesson 14 and the London Square spec table of contents met in Reading lesson 18. Print Documents A to E, one set per pair, so learners can lay them side by side.

Opening (5 min)

Welcome learners. Hold up two pieces of paper. Say: "This drawing says the counter is 600 deep. This one says 650. The cabinets are being built today. Which one do you build?" Let learners argue for a minute. Then tell them every good tender package answers that question in writing, and today they will learn where to look.

This is session 21 of 26 in the Reading lessons. It runs 90 minutes.

Objective (3 min)

By the end of the session, learners will be able to:

  • decide which document in a tender package to open for a given question (Identify the task that requires you to read)
  • find a requirement using a drawing list, a spec table of contents and addenda (Identify the information)
  • follow a requirement across drawings, specs and addenda (Make connections between different parts of the document(s))
  • use the order of precedence to settle a conflict, and recognize when it cannot (Evaluate the document(s))

Pre-assessment (5 min)

  1. "What is the difference between a drawing and a specification?"
  2. "If the plan and a detail disagree, which one would you build to? Why?"

Summary (5 min)

During this session we covered:

  • what is in a tender package: instructions, bid form, contract, drawings, specs and addenda
  • drawings show what and where, specs say which materials, what quality and how
  • finding a spec section by its MasterFormat number
  • addenda are written changes that become part of the documents, and every one goes on the bid form
  • the order of precedence: specs over drawings, larger scale over smaller scale of the same date, written over scaled, later over earlier
  • asking in writing, before the deadline, when the order does not settle it

Total time: 5 + 3 + 5 + 65 + 7 + 5 = 90 minutes.

Notes for the instructor

  • Every package sets its own order. The order in Document A is close to the one in standard Canadian contracts, but some owners change it. That is why Key idea 5 ends "read the order in your package".
  • Task 8 is a scope clarification, not a proven conflict. Shop priming and priming bare steel on site can both apply. Ask who handles bare or damaged areas at handover, rather than declaring that one specification wins. The aim is to price each trade's scope without gaps or duplication.
  • Task 7 (c). A site visitor's comment changes nothing. Only a written addendum from the architect does (Document A, item 3). Learners should still price Slate Blue.
  • Do not scale. Printed sheets shrink or stretch, so a scaled length is a check, not a dimension. Point back to "do not scale" in Reading lesson 05.
