## Task 9 (level 3)

**No.** 1500 + 2750 + 3000 + 1250 = 8500. The overall says 8600. The string is **100 mm** short of the overall.

What to do: do not set forms from a guess. Tell the foreman and send a written question (an RFI) to the engineer or designer asking which size is correct. Check other drawings (the plan, the structural drawings and the latest revision) for the same dimensions. Keep the written answer.

Points a good response covers: shows the sum, gives the 100 mm difference, says not to guess, and says to ask in writing.

## Task 10 (level 3)

a) **12 mm.** There are 4 chain dimensions to the last bolt (1'-0", 5'-0", 6'-0", 6'-0"). Each mark is 3 mm long, so the errors add up: 4 × 3 = 12 mm.
b) **Up to 3 mm.** Each bolt is measured from the end on its own, so the errors do not add up.
c) **Measuring from the baseline** (one end) is better. The bolts must line up with fixed holes in a base plate. With chain measuring, small errors add up along the wall. With baseline measuring, each bolt is only as far off as one measurement.
