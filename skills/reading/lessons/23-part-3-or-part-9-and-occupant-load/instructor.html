Part 3 or Part 9 and the occupant load

Read the BC Building Code articles that decide whether a building falls under Part 3 or Part 9, classify a building by its major occupancy, and work out an occupant load from Table 3.1.17.1.

  • Learner
  • Instructor🔒 (instructor code)
  • Answers🔒 (instructor code)
  • Level: 2-3
  • Time: 90 min
  • Components: Identify the information; Make connections between different parts of the document(s); Understand and apply the information; Evaluate the document(s)

Session 23 of 26 in the Reading lessons · 90 minutes

Before the session: learners need a device that can open the BC Building Code 2024 PDF (about 16 MB), or shared devices. Download it ahead of time in case the internet is slow. Open the BC Code revisions page too, for Task 9. This lesson builds on Reading lesson 6 (Find a rule in the BC Building Code), which taught the numbering system, italics and "shall". Learners who missed lesson 6 should do its Key ideas first. If you print Code pages, read the "Acknowledgements and copyright" section on the BC Building Code 2024 web page first.

Opening (5 min)

Welcome learners. Ask: "Have you ever seen a sign beside a restaurant or hall door that says 'Occupant load' and a number? Who decides that number?" Take a few answers. Then show two buildings side by side on the screen, a house and a four-storey apartment building, and ask whether the same rule book applies to both. Tell learners that the Code splits buildings into Part 9 (houses and small buildings) and Part 3 (larger buildings and some special uses), and that a crew that does not know which Part a job is under can follow the wrong rules all the way through. Today learners find the exact Code words that decide it, and work out an occupant load.

This is session 23 of 26 in the Reading lessons. It runs 90 minutes.

Objective (3 min)

By the end of the session, learners will be able to:

  • find the Articles, definitions and tables that decide which Part applies (Identify the information)
  • connect a building's use, height and area to Table 3.1.2.1., the definitions in Division A and Sentences 1.3.3.2.(1) and 1.3.3.3.(1) (Make connections between different parts of the document(s))
  • classify a building as Part 3 or Part 9 and calculate an occupant load from Table 3.1.17.1. (Understand and apply the information)
  • judge a "rule of thumb" against the current Code and its revisions (Evaluate the document(s))

Pre-assessment (5 min)

  1. "A building is three storeys and 500 m². Is it Part 9?" (The point to draw out: it depends on what the building is used for. Do not give the answer yet.)
  2. "If a floor is 186 m² and the Code allows 9.30 m² for each person, how many people is it designed for?"

Post-assessment (9 min)

  1. "A one-storey bank of 350 m². Part 3 or Part 9? Give the Sentence." (Part 9: banks are Group D, 1 storey, 350 m² does not exceed 600 m². Sentence 1.3.3.3.(1).)
  2. "A one-storey community hall of 300 m². Part 3 or Part 9? Why?" (Part 3: community halls are Group A, Division 2, which is Part 3 at any size. Sentence 1.3.3.2.(1).)
  3. "A classroom is 92.5 m². What is its occupant load?" (92.5 ÷ 1.85 = 50 persons.)

Summary (6 min)

During this session we covered:

  • where the Code decides Part 3 or Part 9: Division A, Articles 1.3.3.2. and 1.3.3.3.
  • the three Part 9 tests: building height, building area and major occupancy
  • the defined words building area, storey, first storey, basement, building height and grade
  • major occupancy groups in Table 3.1.2.1. and the examples in Note A-3.1.2.1.(1)
  • occupant load from Table 3.1.17.1., and using the greatest value when a room has more than one use
  • checking the revisions page, using Revision 3 as the example

Total time: 5 + 3 + 5 + 62 + 9 + 6 = 90 minutes.

Notes for the instructor

  • Which PDF. The Province's web PDF of the Code may not include every revision. Revision 3 (single exit stairs) replaced Article 1.3.3.3. in August 2024, so a learner with an older PDF will see Sentence (1) without the words "Except as provided in Sentence (2)". The three tests are the same in both versions. Use this as a live example of Key idea 7.
  • Article 1.3.3.2. Later revisions added more Sentences to Article 1.3.3.2. for special cases. This lesson uses only Sentence (1).
  • Rounding. The Code does not tell you how to round an occupant load that is not a whole number, so every area in this lesson divides evenly. If a learner brings a real example that does not, tell them the designer sets the number, and do not invent a rule.
  • The designer decides. Learners are not being trained to classify buildings for permits. The point is to read the Code words the designer used, so a crew member can understand the code review sheet on a drawing set and ask good questions.
  • Daycare. Task 3 building F is there on purpose: Article 3.1.2.8. classifies a daycare facility for children as Group A, Division 2, which surprises many people.
