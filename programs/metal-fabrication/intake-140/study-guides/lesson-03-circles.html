Lesson 3. Circles

Find the distance around a circle: the circumference.

Listen

The voice reads this lesson slowly. Pause any time. Play it again as often as you like.

  1. The rule: around = π × across.

    C = π × D

  2. Radius is half. Diameter is 2 × radius.

    r = 16 1/2", so D = 33"

  3. Multiply by π. Use the π key.

    C = π × 33 = 103.6725576"

    On the TI-30Xa

    16.5×2×π=

    Screen 103.6725576

  4. Make it a tape length. Decimal part × 16.

    0.6725576 × 16 = 10.76 → 11/16

    On the TI-30Xa

    .6725576×16=

    Screen 10.7609216

  5. Answer.

    103 11/16" = 8'-7 11/16"

  1. Fraction to decimal.

    18 3/4" = 18.75"

  2. C = π × D.

    π × 18.75 = 58.9049"

Worked example 2. A tank in feet

Watch out: Using the radius instead of the diameter.

C = π × D. If the drawing gives r, double it first.
